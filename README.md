# План похудения

12-недельный план питания, тренировок и шагов по дням. Работает на телефоне как отдельное приложение, в том числе без интернета.

**Открыть:** https://lin0911953831-coder.github.io/plan/

## Установка на iPhone

1. Откройте ссылку выше в Safari.
2. Нажмите «Поделиться» → «На экран «Домой»» → «Добавить».
3. Запускайте приложение с иконки «План».

При первом запуске приложение спросит пол, возраст, рост, вес и дату старта.

## Где хранятся данные

Записи (вес, шаги, отметки) хранятся только в памяти телефона, внутри приложения. На сервер ничего не отправляется. Резервную копию можно сохранить во вкладке «Прогресс».
