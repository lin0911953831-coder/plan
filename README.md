# Здоровое тело

12-недельный план питания, тренировок и шагов по дням, который подбирается под цель (похудеть, держать вес, набрать массу), одну из 5 ступеней физической формы и домашний инвентарь (турник, резинки, гантели). Работает на телефоне как отдельное приложение, в том числе без интернета.

**Открыть:** https://lin0911953831-coder.github.io/plan/

## Установка на iPhone

1. Откройте ссылку выше в Safari.
2. Нажмите «Поделиться» → «На экран «Домой»» → «Добавить».
3. Запускайте приложение с иконки «Здоровое тело».

При первом запуске приложение спросит пол, возраст, рост, вес, цель, уровень формы, инвентарь, здоровье и дату старта.


## Где хранятся данные

Записи (вес, шаги, отметки) хранятся только в памяти телефона, внутри приложения. На сервер ничего не отправляется. Резервную копию можно сохранить во вкладке «Прогресс».

## Условия использования

- Только для взрослых: пользоваться приложением можно с 18 лет.
- Это информационное приложение, а не медицинская помощь. Его авторы не врачи, не диетологи и не тренеры. Планы и цифры рассчитываются по общим формулам и являются примерными ориентирами.
- Все рекомендации носят ознакомительный и добровольный характер. Пользователь сам решает, следовать ли им, и сам отвечает за своё здоровье.
- Перед началом программы рекомендуется проконсультироваться с врачом, а при беременности, кормлении грудью, хронических болезнях, приёме лекарств и сильно повышенном или пониженном весе — обязательно.
- При боли в груди, головокружении, сильной одышке, резкой боли в суставе или спине занятие нужно прекратить и обратиться за медицинской помощью.
- Результаты не гарантируются.
